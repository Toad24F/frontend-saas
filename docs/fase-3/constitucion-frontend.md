# Constitución frontend — Fase 3, Módulo 2

1. Mantener el stack actual: Vite, JavaScript ES Modules, HTML, CSS y Bootstrap, sin añadir dependencias sin justificación.
2. Usar exclusivamente las rutas y contratos implementados por el backend; no simular datos en la versión conectada.
3. Mantener separadas la demo, la interfaz conectada y los componentes realmente compartidos.
4. Respetar los permisos de Administrador, Recepción y Profesional; el backend conserva la autorización definitiva.
5. Derivar el negocio y la identidad de la sesión; nunca enviar ni aceptar un `negocioId` desde formularios.
6. Distinguir configuración, proyección, disponibilidad, validación y citas afectadas como conceptos visibles diferentes.
7. No presentar una ranura consultada o validada como reservada, apartada o garantizada.
8. Implementar estados accesibles de carga, vacío, éxito, error y reintento, sin ocultar fallos técnicos como agendas vacías.
9. Conservar la identidad visual, tema claro/oscuro, navegación por teclado y diseño adaptable sin desplazamiento horizontal.
10. Validar entradas antes de enviarlas y mostrar errores junto al campo o acción correspondiente.
11. Cubrir transformaciones, permisos, límites de fechas, modalidades y errores HTTP con pruebas automatizadas.
12. No implementar portal público, apartados, creación de citas, clientes, WhatsApp, reportes ni pagos sin contrato backend aprobado.
